Chronic Disease Prediction Website
===========================================

وصف المشروع:
-------------
هذا المشروع عبارة عن موقع ويب تفاعلي لتنبؤ الأمراض المزمنة. 
يقوم المستخدم بإدخال الأعراض التي يعاني منها، ويعرض النظام:
- المرض المتوقع
- توصيات وإرشادات مناسبة

المشروع مبني باستخدام:
----------------------
- لغة البرمجة: Python
- إطار العمل: Flask
- قاعدة البيانات: SQLite
- بيئة التطوير: VS Code
- استضافة: Render

هيكل قاعدة البيانات:
-------------------
- جدول المستخدمين (Users): يحتوي على معلومات المستخدمين، مع تمييز بين المدير والمستخدم العادي.
- جدول التنبؤات (Predictions): يخزن بيانات التنبؤات السابقة لكل مستخدم.

طريقة الاستخدام:
----------------
1. افتح الموقع عبر الرابط الخاص بالاستضافة.
2. سجّل الدخول أو أنشئ حساب جديد.
3. أدخل الأعراض التي تعاني منها في النموذج المخصص.
4. اضغط على زر "تنبؤ" ليعرض النظام المرض المحتمل مع التوصيات.
5. للمستخدم المدير: يمكنه إدارة المستخدمين وعرض جميع التنبؤات.

المتطلبات لتشغيل الكود محليًا:
------------------------------
- Python 3.x
- مكتبات Python: Flask, pandas, sqlite3
-   vs code تحميل الكود وتشغيله من 
- ملف قاعدة البيانات: mrp.db موجود في نفس مجلد المشروع
